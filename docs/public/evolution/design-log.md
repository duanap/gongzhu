# 设计演进

这份日志记录的不是所有代码提交，而是会改变玩家体验的设计决定。

## 让牌局不因离线而停住

早期联机牌局很容易被一个离线玩家拖住。后续设计把“AI 补位”和“离线后 AI 托管、原玩家可恢复”拆开：前者解决开局人数，后者保护正在进行的牌局与原玩家权益。

## 让信息回到牌桌，而不是日志里

传牌、收墩、上一墩和局末回看逐步从抽象文本变成牌桌上的方向、卡牌与快照。玩家应先看懂桌面变化，再决定是否需要查看更细的历史。

## 将移动端视为真实牌桌

横屏相关工作不再只看 CSS 是否旋转，而是关注真实设备方向、手牌可点性、弹窗边界、滚动、声音与动画。这样才能避免截图看似正确、玩家实际无法操作的问题。

## Vue 灰度的原则

当前稳定入口与 Vue 灰度入口并行。迁移的目标是恢复原有的玩法、位置、时序和交互契约，而不是借迁移机会把游戏变成另一个产品。正式切换仍取决于完整验收与可回滚能力。

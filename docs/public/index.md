# Hearts by duanap 游戏设计中心

这是一个把红心大战做成“能读懂、能回看、能一起玩”的联机牌桌的设计档案。

它不只是规则说明：这里记录每个功能解决的玩家体验问题、完整的交互流程、边界条件，以及我们为什么做出这样的取舍。

## 设计原则

### 牌局必须始终可继续

四人牌局最怕一个人离开就停摆。房间会自动补齐 AI，离线玩家可以回到自己的座位；即使暂时由 AI 托管，房主也仍然掌握是否允许接管的最后决定权。

### 规则要严格，反馈要温和

能不能出一张牌由服务端统一判定，避免不同玩家看到不同结果；但玩家收到的是明确的原因、灰化状态和可理解的下一步，而不是冷冰冰的失败。

### 牌桌的每一次变化都应该可感知

传牌、出牌、比牌、收墩、射月和结算不是瞬间跳变。动画、音效、颜色和方向共同说明“发生了什么、发生在谁身上、接下来该谁行动”。

### 手机不是缩水的桌面

移动端优先保证牌桌、手牌、按钮和弹窗在横屏中可读、可点、可滚动；不能获得系统横屏时才使用兼容降级，而不把视觉旋转当作正式体验。

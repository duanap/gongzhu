# 音频来源说明

Vue 客户端当前的牌局音效、互动音效和背景音乐均由浏览器 Web Audio API 在运行时合成，不包含第三方录音、采样、音乐文件或下载素材。

## 背景音乐

设置面板提供 5 个原创程序化曲目预设：

- 湖畔微风
- 星光漫步
- 午后茶园
- 云上纸鸢
- 雨后森林

每个预设只保存节拍、和弦级数、琶音序列和振荡器波形等参数。客户端运行时通过正弦波、三角波及音量包络生成声音；默认关闭，玩家主动开启后才会播放。

## 互动与牌局音效

出牌、传牌、轮到玩家、错误提示、道具发射和道具命中均使用短时振荡器与音量包络合成。道具命中声会在飞行动画抵达头像的冲击阶段触发。

`public/audio/interactions/README.txt` 仅是未来真人配音文件的命名建议，当前发布包中没有对应音频素材。若未来加入录音，应在本文件补充作者、授权范围、授权日期和原始文件校验值。

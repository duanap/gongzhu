# Android / iPhone 真机横屏验收清单

本清单用于 Vue 灰度入口 `https://hearts.duanap.cn/vue/`。根路径 `/` 在全部门槛通过前继续保留旧版。

## 证据硬规则

- 至少使用一台 Android 手机的最新版 Chrome 和一台 iPhone 的最新版 Safari。
- 必须从竖屏开始录像，物理旋转设备到横屏后再进入牌局；录像需同时保留系统状态栏或浏览器边界，证明窗口本身已横屏。
- 横屏画面中，浏览器窗口、网页 viewport 和牌桌内容必须同时宽大于高。只旋转窗口、只旋转网页内容或用 CSS `rotate(90deg)` 的截图均不合格。
- 每台设备保存一段连续录像，并为下列关键阶段各截一张图。文件名使用 `android-chrome-*` 或 `iphone-safari-*` 前缀。
- 截图不得裁掉关闭按钮、操作按钮、手牌、牌桌中心或横向边界；允许面板内部纵向滚动，但不能出现整个页面横向滚动。
- 记录设备型号、系统版本、浏览器版本、测试时间、网络类型和是否以 PWA/普通网页打开。

## 每台设备必走流程

- [ ] 创建房间、加入房间、4 人开始和 AI 补位均可操作。
- [ ] 传牌时可选择 3 张；传出飞牌、换入提示和 3 张换入牌高亮方向正确。
- [ ] 正常出牌、必须跟花色、红桃未破、首墩分牌、非当前玩家和结算忙碌提示完整可见。
- [ ] 第四张牌后先比牌，再向赢家方向收墩；下一墩开始时没有卡死或重复牌。
- [ ] “上一墩”四张牌全部可见，顺序、赢家、分牌和首出花色正确。
- [ ] 甩牌确认框完整位于横屏窗口内，确认后余牌与分数正确结算。
- [ ] 射月先播放月亮动画，再显示事件播报；录像可辨认先后顺序。
- [ ] 本局结束可查看四家完整牌桌；双列内容可滚动，无横向越界。
- [ ] 整场结束显示真实姓名、排名、本局/总分和赢家；仅房主出现“再来一局”。
- [ ] 房主“再来一局”后回到第 1 局，四家本局/总分全部归零。
- [ ] 主动断网后能自动重连；超过托管时间后 AI 接管，原玩家能取回座位。
- [ ] 纯 AI 座位申请、房主批准和拒绝均有明确反馈。

## 工具与设备能力

- [ ] 设置、出牌日志、规则、版本日志、AI 学习和调试各自只有一个面板，关闭按钮与底部操作不重叠。
- [ ] 出牌日志可切换全部、出牌、收墩、传牌和房间筛选；记录保持最新在上，横屏下能够滚动到末尾。
- [ ] 设置面板可滚动到全部六个分区；音效音量从 100% 调到 35% 后实际变小，刷新仍为 35%。
- [ ] 关闭总音效后出牌/错误/射月/互动均静音；关闭互动音效只影响互动声音。
- [ ] 关闭特效后传牌/收墩/射月等视觉层停用；偏快/标准/偏慢的时长差异可感知。
- [ ] 关闭“允许番茄”后番茄道具不可用，其他互动仍可用。
- [ ] 互动按钮位置正常；点击三家头像时道具菜单贴近对应头像且不越界，道具飞向目标牌堆，冷却期间按钮不可重复触发。
- [ ] 规则为 8 条，版本日志首项为 v1.4.20，旧版本可继续向下滚动。
- [ ] 页面不显示手动“横屏”按钮；设备物理旋转后浏览器窗口和网页内容自然横屏，系统方向锁定不可用时只记录降级结果。
- [ ] “全屏/缩小”可以独立进入和退出，不把仅改变按钮文案视为成功。
- [ ] 清缓存有二次确认，确认后房间身份、重连状态、横屏和设置被清除并重新加载。

## 失败判定

任一设备出现以下情况，本轮真机验收直接失败，不得切换根路径：

- 窗口横屏但网页内容仍按竖屏排版，或网页横向但设备/浏览器窗口仍是竖屏。
- 页面根内容通过 90° CSS 旋转冒充物理横屏。
- 手牌、提示、弹窗、关闭按钮或主要操作超出屏幕且无法在对应面板内部滚动到达。
- 断线后丢座位、重复发牌、无法继续一局，或 AI 接管后无法取回。
- 声音开关/音量与实际声音不一致，或全屏按钮只改变文案而未改变浏览器状态。
